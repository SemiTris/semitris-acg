# 00-命名与品牌

## 项目名称

| 维度 | 值 |
|---|---|
| 项目名 | SemiTris-ACG |
| 中文名 | SemiTris 的 ACG 私宅 |
| 口号 | 只属于我的番剧小窝 |
| 英文代号 | semitris-acg |

## 命名来源

- **SemiTris**：owner 的网名，体现"个人"属性 —— 这是**独属于自己**的站。
- **ACG**：Anime / Comic / Game 的缩写，点明主题是二次元内容。
- 组合语义：*SemiTris 的二次元领地*。

## 各环境标识（全项目统一使用，勿改）

| 用途 | 值 |
|---|---|
| 文件夹名 | semitris-acg |
| 后端 package | com.semitris.acg |
| 数据库名 | semitris_acg |
| 前端工程名 | semitris-acg-web |
| 后端应用名（spring.application.name） | semitris-acg |
| 启动类 | SmTrisAcgApplication |

## 品牌基调

- **风格**：二次元 / 治愈 / 暗色系为主，点缀粉紫渐变。
- **色调建议**：
  - 背景深色：`#1a1a2e`
  - 主色粉：`#ff9ac1`
  - 辅助紫：`#a29bfe`
  - 文字：`#e6e6ef`
- **字体**：中文系统默认 / 思源黑体，标题可加装饰感字体。
- **动效**：卡片 hover 上浮 + 微渐变，克制不花哨。
- **图标/头像**：像素风或 Q 版，后续前端阶段定稿。

> 具体配色、字体、组件库细节在前端阶段由 owner 定稿，本文件仅为方向性指引。

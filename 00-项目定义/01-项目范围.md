# 01-项目范围（MVP 边界）

## 一句话

做一个只能由 SemiTris 自己使用的二次元网站：录入**看过/在看/想看的番剧与漫画**，做**收藏与追番进度**、**评分与评价**、**推荐安利**，页面是好看的二次元风格。

## MVP 内（第一个迭代，约 1~2 周）

1. **番剧资料库 CRUD**：动画/漫画条目（标题、原名、封面、类型、标签、集数、连载状态、年份、简介）。
2. **多条件分页查询**：按标题模糊 / 类型 / 连载状态筛选，PageHelper 分页。
3. **收藏 / 追番**：想看 / 在看 / 已看完 / 搁置 / 最爱 五种状态 + "看到第几集"进度 + 是否加精。
4. **评价**：每部番评分（1~10）+ 一段感想。
5. **推荐安利墙**：把想安利的番放上墙，写推荐理由和标签。
6. **封面上传**：本地文件上传与回显。
7. **二次元风格界面**：卡片墙、详情页、追番列表页、安利墙。

## 本迭代内但可后置（第二个迭代）

- 登录 / 注册（单人站点可先不做；若做则参考课堂最简单实现）。
- 用户头像。
- 数据统计（看过多少部、年度小结）。

## MVP 外（明确不做）

- 多用户 / 好友 / 社区系统。
- 番剧评分排行、他人评论。
- 调用外部 API 拉取番剧数据（**纯手录**，保证数据完全属于自己，也让后端最简单、最贴合课堂知识）。
- 部署上线（可选，学习后期再考虑）。

## 边界理由

- **单人使用** → 不需要复杂权限体系，专注 CRUD 与界面。
- **手录数据** → 不依赖第三方接口，后端只讲课本知识，不会失控。
- **逐步推进** → 每一期只做老师当天知识点对应的一个功能，永不掉队。

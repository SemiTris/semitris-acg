# 03-接口规范

## 1. 统一返回结构 `R<T>`

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

- `code`：200 成功 / 500 失败。
- 静态工厂：`R.success()` / `R.success(data)` / `R.success(msg, data)` / `R.error(msg)`。
- 前端统一拦截：`code=200` 取 data，否则弹出 message。

## 2. URL 与 HTTP 方法语义

| 操作 | 方法 | 路径 |
|---|---|---|
| 新增 | POST | `/{资源}/add` |
| 删除 | DELETE | `/{资源}/delete/{id}` |
| 修改 | PUT | `/{资源}/update`（body 传实体） |
| 详情 | GET | `/{资源}/findById/{id}` |
| 列表分页 | GET | `/{资源}/page?pageNum=&pageSize=&条件...` |
| 列表全量 | GET | `/{资源}/list`（下拉框等场景用） |

资源：`anime` / `collection` / `review` / `recommend` / `user` / `file`。

## 3. 参数传递约定

- **新增 / 修改**：JSON body，`@RequestBody` 接收。
- **删除 / 详情**：路径参数，`@PathVariable("id")`。
- **分页 / 搜索**：`@RequestParam`，`pageNum` / `pageSize` 带默认值。

## 4. 分页规范（PageHelper）

- 入参：`pageNum`（默认 1）、`pageSize`（默认 5）。
- 出参：`PageInfo<T>`，关键字段 `total` / `list` / `pageNum` / `pageSize` / `pages`。
- 前端用 `total` 渲染分页器，用 `list` 渲染数据。

## 5. 命名与时间

- 返回字段由数据库 snake_case 自动映射为 camelCase。
- 时间：MySQL `DATETIME`，前端按需格式化，不返回时间戳。

## 6. 错误处理

- 业务失败返回 `R.error("原因")`（code=500）。
- 不把原生异常抛给前端；全局异常处理作为后置优化项。

## 7. 跨域

- 后端 CORS 全开（参考 sm03 CorsConfig：`/**`、所有 method、允许全部 origin）。
- 开发期任意前端 origin 均可调用。

## 8. 删除的级联约定

- 删除 `anime` 时，同步删除其 `collection` / `review` / `recommend` 记录（先查子表再删，或一次性联表 DELETE）。

## 9. 各模块基础路径速查

| 模块 | 基础路径 | 主要接口 |
|---|---|---|
| 番剧 | `/anime` | add / delete/{id} / update / findById/{id} / list / page |
| 收藏 | `/collection` | add / delete/{id} / update / findByAnime/{animeId} / list |
| 评价 | `/review` | add / update / delete/{id} / listByAnime/{animeId} / page |
| 推荐 | `/recommend` | add / update / delete/{id} / list |
| 用户 | `/user` | add / login / delete/{id} / update / findById/{id} / page |
| 文件 | `/file` | upload / download/{filename} |

详细请求/响应示例见 [03-接口文档](../03-接口文档/anime.md)。

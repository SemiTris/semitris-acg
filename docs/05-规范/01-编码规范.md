# 01-编码规范

## 1. 通用

- 注释用**中文**；类上写一句职责说明（`/** ... */`）。
- 命名：类 PascalCase、方法/变量 camelCase、常量全大写。
- 包名小写：`com.semitris.acg.{controller, service, impl, mapper, entity, util, config}`。

## 2. 分层

- controller：只做参数接收 + 调用 service + 返回 `R<T>`，不写 SQL 逻辑。
- service：接口 + impl 实现。
- mapper：接口 + XML。
- **不允许 controller 直接注入 mapper**，保持分层清晰。

## 3. Controller 规范

- 方法路径固定：`/add` `/delete/{id}` `/update` `/findById/{id}` `/page` `/list`。
- 新增 / 修改用 `@RequestBody`；删除 / 详情用 `@PathVariable("id")`。
- 分页参数带默认值：`@RequestParam(value = "pageNum", defaultValue = "1") Integer pageNum`。
- 可选条件参数用 `required = false`。

## 4. MyBatis XML 规范

- `resultType` / `parameterType` 用 type-aliases 别名（类名，如 `Anime`）。
- 多条件查询用 `<where>` + `<if>`；动态更新用 `<set>` + `<if>`。
- 模糊查询用 `CONCAT('%', #{xx}, '%')`。
- 每张表一个 XML，`namespace` 指向对应 Mapper 接口。
- 联表查询：`LEFT JOIN anime`，把 `title` / `cover` 映射到非持久化字段。

## 5. 返回规范

- 所有接口返回 `R<T>`；成功 `R.success(...)`，失败 `R.error("原因")`。

## 6. 时间

- 实体统一用 `java.time.LocalDateTime`；数据库 `DATETIME DEFAULT CURRENT_TIMESTAMP`（存量 User 实体的 `Date` 不迁移）。

## 7. 联表补充字段

- 需要在返回里附带他表字段时（如 Collection 的 title/cover），直接在实体里加非持久化字段即可，无需额外 DTO。

## 8. 复制粘贴原则

> 各分层写法以项目内既有样板为准：Controller / Service / Mapper + XML 的完成形态参照 `backend/src/main/java/com/semitris/acg` 的 **User 模块**，其余模块按相同模式扩展（把 User 替换为目标模型）。

# 03-素材与封面规范

## 1. 封面图片

- **尺寸**：建议 300×400（竖版 3:4），与卡片墙观感最协调。
- **格式**：JPG / PNG / WebP。
- **大小**：单张 ≤ 500KB（过大会拖慢页面加载）。
- **来源**：官方海报、无版权图库，仅供个人学习演示。

## 2. 存放与命名

- 上传目录：`D:/upload/`（application.yaml：`semitris.upload.dir`）。
- 文件名**避免中文和空格**：`{时间戳}.jpg` 或 `{animeId}_{type}.jpg`。
- 访问：`http://localhost:8080/file/download/{文件名}`。

## 3. 无图兜底

- 无封面时前端显示占位图（渐变底 + 占位文案），保证卡片不破版。

## 4. 站点配色基调（前端定稿）

| 元素 | 建议值 |
|---|---|
| 背景深色 | `#1a1a2e` |
| 主色粉 | `#ff9ac1` |
| 辅助紫 | `#a29bfe` |
| 文字 | `#e6e6ef` |
| 字体 | 中文系统默认 / 思源黑体，标题可加装饰感字体 |
| 动效 | 卡片 hover 上浮 + 微渐变 |

## 5. 版权提醒

- 封面/图片仅作**个人学习**用途，不对外发布商业用途，注意版权。

ACG 追番收藏站点
数据库设计文档

面向单人 ACG 追番收藏场景的关系型数据库设计，涵盖用户、番剧资料、收藏追番、评价打分、推荐分享五大核心模块。 预留多用户扩展能力，修复原设计中的精度缺陷与级联约束问题。

数据库：semitris_acg 表数量：5 字符集：utf8mb4 引擎：InnoDB

04 / DDL

完整建表语句

可直接复制执行的 MySQL DDL 脚本，包含建库、建表、外键约束与索引。

semitris_acg_schema.sql 
-- ============================================
-- semitris_acg 数据库设计（优化版）
-- 修复：rating 精度、外键级联、预留多用户
-- ============================================

CREATE DATABASE IF NOT EXISTS semitris_acg
  DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

USE semitris_acg;

-- --------------------------------------------
-- 1. user 用户表
-- --------------------------------------------
CREATE TABLE `user` (
    id            BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键',
    username      VARCHAR(50)  NOT NULL COMMENT '账号',
    password      VARCHAR(64)  NOT NULL COMMENT '密码，BCrypt加密存储，禁止MD5',
    nickname      VARCHAR(50)  DEFAULT NULL COMMENT '昵称',
    avatar        VARCHAR(255) DEFAULT NULL COMMENT '头像 URL',
    register_time DATETIME     DEFAULT CURRENT_TIMESTAMP COMMENT '注册时间',
    update_time   DATETIME     DEFAULT NULL ON UPDATE CURRENT_TIMESTAMP COMMENT '信息更新时间',
    PRIMARY KEY (id),
    UNIQUE KEY uk_username (username)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表（预留多用户，单人站点可仅插入1条用户数据）';

-- --------------------------------------------
-- 2. anime 番剧/漫画表
-- --------------------------------------------
CREATE TABLE `anime` (
    id             BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键',
    title          VARCHAR(100) NOT NULL COMMENT '中文标题',
    original_title VARCHAR(100) DEFAULT NULL COMMENT '原名',
    cover          VARCHAR(255) DEFAULT NULL COMMENT '封面图片 URL',
    type           TINYINT      DEFAULT 1 COMMENT '类型：1=动画 2=漫画',
    genre          VARCHAR(100) DEFAULT NULL COMMENT '类型标签，逗号分隔；大数据量建议拆标签中间表',
    episodes       INT          DEFAULT 0 COMMENT '集数/话数，业务保证>=0',
    status         TINYINT      DEFAULT 0 COMMENT '连载状态：0=连载中 1=已完结',
    year           INT          DEFAULT NULL COMMENT '播出/连载年份',
    rating         DECIMAL(3,1) DEFAULT NULL COMMENT '平均评分（0.0 ~ 10.0），冗余字段，review变更需同步更新',
    synopsis       TEXT         COMMENT '简介',
    created_at     DATETIME     DEFAULT CURRENT_TIMESTAMP COMMENT '录入时间',
    updated_at     DATETIME     DEFAULT NULL ON UPDATE CURRENT_TIMESTAMP COMMENT '修改时间',
    PRIMARY KEY (id),
    KEY idx_type (type),
    KEY idx_title (title)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='番剧/漫画资料表';

-- --------------------------------------------
-- 3. collection 收藏/追番表
-- --------------------------------------------
CREATE TABLE `collection` (
    id         BIGINT   NOT NULL AUTO_INCREMENT COMMENT '主键',
    user_id    BIGINT   NOT NULL COMMENT '用户ID',
    anime_id   BIGINT   NOT NULL COMMENT '番剧 ID',
    list_type  TINYINT  DEFAULT 1 COMMENT '收藏类型：1=想看 2=在看 3=已看完 4=搁置 5=最爱',
    progress   INT      DEFAULT 0 COMMENT '看到第几集/话，业务校验0 <= progress <= episodes',
    favorite   TINYINT  DEFAULT 0 COMMENT '是否加精收藏：0=否 1=是',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '收藏时间',
    updated_at DATETIME DEFAULT NULL ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (id),
    UNIQUE KEY uk_user_anime (user_id, anime_id),
    CONSTRAINT fk_collection_user FOREIGN KEY (user_id) REFERENCES `user` (id) ON DELETE CASCADE,
    CONSTRAINT fk_collection_anime FOREIGN KEY (anime_id) REFERENCES anime (id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='收藏/追番表';

-- --------------------------------------------
-- 4. review 评价表
-- --------------------------------------------
CREATE TABLE `review` (
    id         BIGINT   NOT NULL AUTO_INCREMENT COMMENT '主键',
    user_id    BIGINT   NOT NULL COMMENT '用户ID',
    anime_id   BIGINT   NOT NULL COMMENT '番剧 ID',
    rating     INT      NOT NULL COMMENT '评分（1 ~ 10）',
    content    TEXT     COMMENT '评价内容',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '评价时间',
    updated_at DATETIME DEFAULT NULL ON UPDATE CURRENT_TIMESTAMP COMMENT '修改时间',
    PRIMARY KEY (id),
    KEY idx_anime (anime_id),
    KEY idx_user (user_id),
    CONSTRAINT fk_review_user FOREIGN KEY (user_id) REFERENCES `user` (id) ON DELETE CASCADE,
    CONSTRAINT fk_review_anime FOREIGN KEY (anime_id) REFERENCES anime (id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='评价表';

-- --------------------------------------------
-- 5. recommend 推荐表
-- --------------------------------------------
CREATE TABLE `recommend` (
    id         BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键',
    user_id    BIGINT       NOT NULL COMMENT '用户ID',
    anime_id   BIGINT       NOT NULL COMMENT '番剧 ID',
    reason     VARCHAR(255) DEFAULT NULL COMMENT '推荐理由',
    tags       VARCHAR(100) DEFAULT NULL COMMENT '推荐标签，如：治愈,神作',
    created_at DATETIME     DEFAULT CURRENT_TIMESTAMP COMMENT '推荐时间',
    updated_at DATETIME     DEFAULT NULL ON UPDATE CURRENT_TIMESTAMP COMMENT '修改时间',
    PRIMARY KEY (id),
    KEY idx_anime (anime_id),
    KEY idx_user (user_id),
    CONSTRAINT fk_recommend_user FOREIGN KEY (user_id) REFERENCES `user` (id) ON DELETE CASCADE,
    CONSTRAINT fk_recommend_anime FOREIGN KEY (anime_id) REFERENCES anime (id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='推荐表';
05 / OPTIMIZATION

优化说明

相比原设计，本次优化修复了精度缺陷、完善了级联约束、预留了多用户扩展能力。

BUG 修复 rating 精度修复

原设计 DECIMAL(2,1) 最大只能存 9.9，无法存储 10.0 满分。 已修改为 DECIMAL(3,1)，支持 0.0 ~ 10.0 完整评分范围。

BUG 修复 外键级联删除

原设计外键未指定 ON DELETE，默认 RESTRICT 导致存在子记录时无法删除番剧。 已统一添加 ON DELETE CASCADE，删除番剧自动清理关联的收藏、评价、推荐。

结构优化 预留多用户扩展

原设计业务表缺少 user_id，仅支持严格单人场景。 已在 collection、review、recommend 表增加 user_id 字段与外键， 联合唯一索引改为 uk_user_anime(user_id, anime_id)，未来可无缝扩展多用户。

结构优化 补充更新时间字段

原设计 user、review、recommend 表缺少更新时间。 已统一补充 updated_at / update_time 字段， 使用 ON UPDATE CURRENT_TIMESTAMP 自动维护。

安全增强 密码加密方案

原设计注释使用 MD5 存储密码，存在撞库风险。 已修改注释明确要求使用 BCrypt 加密存储， 字段长度 VARCHAR(64) 可容纳 BCrypt 哈希结果。

业务约束 冗余字段一致性

anime.rating 为冗余计算字段，存储 review 表评分的平均值。 业务层必须在新增、修改、删除 review 时重新 AVG 计算并更新此字段， 否则会出现数据不一致。如需强一致性可考虑去掉此字段，查询时实时聚合。

扩展性 标签字段说明

genre、tags 使用逗号分隔字符串，适合小体量单人项目。 如后续需要标签筛选、统计、关联查询，建议新建 tag 与 anime_tag 中间表实现多对多关系。

扩展性 推荐表扩展建议

当前 recommend 表仅支持对单部番写推荐评语。 如需实现「看了 A 推荐 B」的相似番剧推荐场景， 可增加 target_anime_id BIGINT 字段表达推荐目标。

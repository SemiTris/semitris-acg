# PRD 产品需求文档

## 1. 背景

个人二次元收藏站点：对观看/收藏的番剧与漫画做资料库管理、收藏追番、评价与推荐。纯手录数据，前后端分离开发。

## 2. 目标

- **能力**：后端 CRUD / 分页 / 搜索 / 上传 / 关联查询 / 前后端联调。
- **产出**：可用的个人网站（二次元风格）。
- **约束**：按迭代规划推进，一次一个功能点，质量优先。

## 3. 用户

- **唯一使用者**：SemiTris。
- **用户画像**：动漫/漫画爱好者，想拥有一个自己动手建的、独属于自己的内容收藏库。

## 4. 功能需求

### 4.1 番剧资料库（P0）

| 编号 | 需求 | 说明 |
|---|---|---|
| A-01 | 新增番剧 | 标题/原名/类型(动画 or 漫画)/封面/类型标签/集数/连载状态/年份/简介 |
| A-02 | 删除番剧 | 按 id 删除，级联清理其收藏/评价/推荐 |
| A-03 | 修改番剧 | 编辑任意字段，只更新传入的非空字段 |
| A-04 | 查询详情 | 按 id 查单条 |
| A-05 | 列表 | 卡片墙展示，分页 |
| A-06 | 多条件搜索 | 标题模糊、类型等值、连载状态等值，条件可组合 |

### 4.2 收藏 / 追番（P0）

| 编号 | 需求 | 说明 |
|---|---|---|
| C-01 | 加入收藏 | 标记为 想看/在看/看完/搁置/最爱 |
| C-02 | 更新状态与进度 | 改 list_type / progress（看到第几集）/ favorite（是否加精） |
| C-03 | 追番列表 | 展示已收藏的番（带封面、标题、进度、状态），可按状态筛选 |
| C-04 | 取消收藏 | 删除收藏记录 |

### 4.3 评价（P1）

| 编号 | 需求 | 说明 |
|---|---|---|
| R-01 | 写评价 | 对一部番评分(1~10) + 感想 |
| R-02 | 改 / 删评价 | 编辑或删除 |
| R-03 | 查看评价 | 详情页展示该番的全部评价 |

### 4.4 推荐安利墙（P1）

| 编号 | 需求 | 说明 |
|---|---|---|
| E-01 | 推荐一部番 | 选番 + 推荐理由 + 标签 |
| E-02 | 安利墙列表 | 展示推荐（带番信息、理由、标签） |

### 4.5 用户与文件（P2）

- 用户：简单注册/登录（可后置到第二迭代）。
- 文件：封面/头像上传。

## 5. 非功能需求

- 所有接口返回统一 `R<T>`，前端统一处理 code / message。
- 接口 URL 语义化（`/anime/add`、`/collection/list` …）。
- 数据库 utf8mb4，支持中文与 emoji（例如简介里可能出现 `🥲`）。
- 前端页面二次元风格，暗色系为主。
- 分页/搜索响应迅速（数据量小，无性能压力）。

## 6. 页面清单（前端阶段规划）

| 页面 | 路由建议 | 主要功能 |
|---|---|---|
| 番剧卡片墙 | /anime | 分页列表、搜索、筛选、新增/编辑/删除入口 |
| 番剧编辑弹窗/页 | — | 新增/编辑表单（含封面上传） |
| 番剧详情页 | /anime/:id | 简介 + 收藏操作 + 评价列表 + 写评价 |
| 追番列表页 | /collection | 按状态展示追番，更新进度 |
| 安利墙 | /recommend | 推荐卡片列表 |
| 登录页（可选） | /login | 登录 |

## 7. 整体验收口径

- 所有后端接口可用 Postman 调通，返回结构一致。
- 前端每个页面操作对应真实接口，数据不写死。
- 每个功能点按《用户故事与验收标准.md》逐条验收。

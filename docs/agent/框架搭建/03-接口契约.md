# 03-接口契约（框架搭建）

## 结论：接口契约保持不变，仅文档迁移位置

- 接口文档整体迁入 `docs/03-接口文档/`（原顶层 `03-接口文档/`），内容未改。
- 六大模块契约（anime/collection/review/recommend/file/user）、统一 `R<T>`、PageHelper 分页、路径风格等**一律不变**。
- 后续实现必须以 `docs/03-接口文档/*.md` 为准，不得自创接口。

## 对实现阶段的约束（供 Claude Code 开工阅读）

1. 路径统一 `/add` `/delete/{id}` `/update` `/findById/{id}` `/page` `/list`（详见 `docs/05-规范/01-编码规范.md`）。
2. 返回统一 `R<T>`；分页返回 `PageInfo`。
3. user_id 不进 API；删除靠外键级联，Service 不手工删子表。

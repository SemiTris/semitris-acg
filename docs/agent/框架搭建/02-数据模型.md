# 02-数据模型（框架搭建）

## 结论：schema 保持不变，仅迁移脚本位置

- 权威 DDL 文档：`docs/02-技术设计/02-数据库设计_优化版.md`（唯一权威版本）。
- 可执行脚本：原 `backend/sql/init.sql` → 迁移为 `database/init.sql`（**唯一入口**）。
- 5 张表、外键 `ON DELETE CASCADE`、`DECIMAL(3,1) rating`、BCrypt 密码列宽 `VARCHAR(64)`、`utf8mb4_unicode_ci` 等**全部不变**。

## 数据库脚本约定（延续 AGENTS.md）

- `database/init.sql` 可重复执行（先 DROP 再 CREATE）——仅限开发环境。
- 业务表 `user_id` 由后端常量 `DEFAULT_USER_ID = 1L` 填充，脚本写入初始用户 `id=1`。
- 迁移/生产库变更走 ADR 审批，禁止未经确认的 DB 写操作。

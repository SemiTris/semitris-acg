# 02-学习同步对照表

> **核心工具**：把老师每一天讲的知识点，当天映射到 SemiTris-ACG 上。
> **使用方法**：每天课后第一件事，更新"今天"这一行 —— 老师实际讲了什么，就把它抄到"你项目要做的"列，然后当天完成。

| 天 | 老师课程（预计：用户管理系统） | 你项目要做的后端 | 你项目要做的前端 | 巩固的知识点 |
|---|---|---|---|---|
| 0 | 开课准备 | 建库建表、Spring Initializr、application.yaml | — | Spring Boot 启动、MyBatis 配置 |
| 1 | 项目搭建 + 查全部 | anime 基础查询（全表 findAll） | 番剧卡片墙（真实数据） | 实体 / Mapper / XML / Service / Controller 分层 |
| 2 | 新增 + 删除 | anime add / delete | 新增模态框 + 删除 | `@RequestBody`、动态 SQL insert / delete |
| 3 | 修改 | anime update | 编辑弹窗（复用表单） | `<set>` 动态更新 |
| 4 | 分页 | anime page（PageHelper） | 分页组件 | PageHelper + PageInfo |
| 5 | 多条件 / 模糊搜索 | anime 条件查询 | 搜索栏 + 筛选 Tab | `<where>` / `<if>` / `LIKE CONCAT` |
| 6 | 文件上传 | FileController 上传/回显 | 封面上传 | multipart、文件存取 |
| 7 | 登录 / 关联查询 | collection + review（含连表） | 追番列表页 + 详情页评论 | JOIN、外键、1:N |
| 8 | 前后端联调 + 美化 | recommend | 安利墙 + 二次元主题 | 联调、CSS / 组件库 |

## 说明

- 每一行 = 一天内"你项目"的**完整闭环**：后端接口 + 前端页面 + 验收。
- 老师若当天多讲 / 少讲，**平移**即可；核心是"当天知识点当天用"，不要攒。
- collection / review / recommend 大量复用了前几天的 CRUD 模式 —— 越到后面写得越快，这就是复用的意义。

## 使用示例（第 1 天）

```
老师今天讲了：建项目 + User 实体 + 全表查询接口
你今天照做：   建 semitris-acg 后端 → Anime 实体 → AnimeMapper(+XML) → AnimeService → AnimeController 的 list 接口
前端成果：      Vue 卡片墙，axios 调 /anime/list，真实数据渲染
验收：         Postman 调 /anime/list 通；页面能看到录进去的番
```

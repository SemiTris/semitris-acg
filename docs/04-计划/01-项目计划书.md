# 01-项目计划书

## 1. 项目概述

SemiTris-ACG：个人二次元网站。以课堂"用户管理系统"为镜像，同步构建，**一天一个知识点，永不掉队**。后端接口在本计划第 1~8 天内逐步由 owner 亲手编写完成（不是一次性写完）。

## 2. 里程碑

| 里程碑 | 内容 | 时间 |
|---|---|---|
| M0 准备 | 本文档包、建库建表、项目骨架 | 第 0 天（今天） |
| M1 番剧库 | anime 完整 CRUD + 分页 + 搜索 + 前端卡片墙 | 第 1 ~ 5 天 |
| M2 收藏与评价 | collection + review（含连表）+ 前端追番列表/详情 | 第 7 天 |
| M3 安利与美化 | recommend + 全站二次元主题 | 第 8 天 |
| M4 可选 | 登录、部署上线 | 后期 |

## 3. 每日任务（与老师同步，详见对照表）

| 天 | 目标 | 后端任务 | 前端任务 | 验收 |
|---|---|---|---|---|
| 0 | 骨架就绪 | 建库建表、Spring Initializr 建工程、application.yaml、依赖 | — | 后端能启动、5 张表已建 |
| 1 | 查全部 | anime 实体/Mapper/Service/Controller 全量查询 | 卡片墙静态渲染真实数据 | 接口通、页面出数据 |
| 2 | 新增 + 删除 | anime add / delete | 新增模态框 + 删除按钮（二次确认） | 能增能删 |
| 3 | 修改 | anime update | 编辑弹窗（复用表单） | 能改且同步 |
| 4 | 分页 | anime page（PageHelper） | 分页组件 | 翻页正确 |
| 5 | 多条件搜索 | anime 条件查询（title/type/status） | 搜索栏 + 筛选 Tab | 条件组合正确 |
| 6 | 文件上传 | FileController 上传/回显 | 封面上传/选图 | 上传成功并回显 |
| 7 | 关联查询 | collection + review（含连表） | 追番列表页 + 详情页评论评分 | 连表数据正确 |
| 8 | 整合美化 | recommend | 安利墙 + 全站二次元主题 | 全功能联调通过 |

## 4. 风险与应对

| 风险 | 应对 |
|---|---|
| 老师节奏 / 内容与预估不同 | 对照表只是模板，每天按老师**实际**内容平移对应知识点即可 |
| 前后端技术栈不同（Element Plus / UI） | 接口与前端解耦，只影响前端代码，后端不动 |
| 当天时间不够 | 每天只一个小目标，允许顺延，**宁慢勿缺**，不要攒 |
| 连表查询难度 | 第 7 天专门留时间，先画 JOIN 结构图再动手 |

## 5. 完成标准（Definition of Done）

- 接口级：Postman 全部调通，返回结构一致，无硬编码数据。
- 功能级：按《用户故事与验收标准.md》逐条验收。
- 代码级：遵循《编码规范》，提交信息遵循《Git 规范》。

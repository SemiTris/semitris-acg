# 01-项目计划书

## 1. 项目概述

SemiTris-ACG：个人二次元网站（番剧资料库 + 收藏/追番 + 评价 + 推荐安利墙 + 封面上传）。前后端分离，纯手录数据。后端位于 `backend/`，前端 `frontend/`（待建）。按迭代推进，一次一个功能点，质量优先。

## 2. 里程碑

| 里程碑 | 内容 | 计划 |
|---|---|---|
| M0 骨架 | 文档包、建库建表、后端工程、AI 协作初始化 | ✅ 已完成 |
| M1 番剧库 | anime 完整 CRUD + 分页 + 搜索 + 前端卡片墙 | 迭代 1 |
| M2 收藏与评价 | collection + review（含连表）+ 前端追番列表/详情 | 迭代 2 |
| M3 安利与美化 | recommend + 全站二次元主题 | 迭代 3 |
| M4 可选 | 登录、文件上传联调、部署上线 | 后期 |

## 3. 迭代任务

| 迭代 | 目标 | 后端任务 | 前端任务 | 验收 |
|---|---|---|---|---|
| 1 | 番剧资料库 | Anime 实体已有，补 Mapper+XML / Service / Controller：list / add / delete / update / findById / page + 条件搜索 | 卡片墙（分页、搜索、筛选）、新增/编辑弹窗、删除二次确认 | 接口全通，页面走真实数据 |
| 2 | 收藏与评价 | Collection、Review 模块（含连表返回 title/cover，review 事务内重算 rating） | 追番列表页、详情页收藏操作 + 评分评价 | 连表数据正确，评分联动 |
| 3 | 安利与美化 | Recommend 模块（连表）；File 上传/回显 | 安利墙、封面上传、全站二次元主题 | 全功能联调通过 |
| 4 | 可选 | user 登录（BCrypt matches）；统计 | 登录页（可选） | 按需验收 |

## 4. 风险与应对

| 风险 | 应对 |
|---|---|
| 模块间契约漂移 | 实现以 `docs/03-接口文档/` 为准，改动先走变更记录 |
| 联表查询复杂度 | 连表前先明确 JOIN 结构，遵循 `docs/05-规范/01-编码规范.md` 联表约定 |
| 迭代时间不足 | 一次只提一个小目标，允许顺延，宁慢勿缺 |
| 前后端联调阻塞 | 接口先行，前端按契约联调，后端不因前端未就绪返工 |

## 5. 完成标准（Definition of Done）

- 接口级：Postman 全部调通，返回结构一致，无硬编码数据。
- 功能级：按 `docs/01-需求/用户故事与验收标准.md` 逐条验收。
- 代码级：遵循 `docs/05-规范/01-编码规范.md`，提交信息遵循 `docs/05-规范/02-Git与工程规范.md`。

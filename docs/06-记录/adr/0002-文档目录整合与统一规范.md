# ADR-0002：docs 文档目录整合与统一规范

- **日期**：2026-09-18
- **状态**：已采纳（人类确认方案 A）
- **决策者**：SemiTris（人类）确认；OpenCode 起草

## 背景

框架搭建后 `docs/` 下同时存在两类布局：编号目录（`00~05`）与游离目录（`adr/`、`agent/`、`设计可视化/`），编号与命名风格不统一；废弃文档（`02-数据库设计.md` 初版）与权威版并存，易误读；缺少统一导航。

## 决策

1. 统一编号分层：`00-项目定义 ~ 05-规范`（原样保留）＋新增：
   - `06-记录/`：含 `adr/`（NNNN-标题.md）与 `历史/`（废弃/过期文档归档）；
   - `07-协作/`：原 `agent/` 归口，直接放 `<功能>/` 设计包；
   - `assets/`：非 Markdown 资产（设计可视化 HTML）。
2. 废弃文档移入 `06-记录/历史/`，头部保留「以 XX 为准」说明。
3. 新增 `docs/README.md` 作为总导航唯一入口。
4. 新增 `docs/05-规范/04-文档目录规范.md` 固化命名与放置规则。
5. 全局约定中的 `docs/adr/`、`docs/agent/` 在本项目落地为 `docs/06-记录/adr/`、`docs/07-协作/`（语义不变，仅归入编号体系）。

## 影响

- `docs/adr/`→`docs/06-记录/adr/`、`docs/agent/`→`docs/07-协作/`、`docs/设计可视化/`→`docs/assets/`、废弃库设计→`06-记录/历史/`，相关引用需同步。
- README.md / AGENTS.md 中的目录描述更新为最终形态。
- 数据库 schema、接口契约、代码规范**不受影响**。

## 替代方案

- 轻量方案（仅加导航、保留游离目录）：编号不统一问题仍在，否决。
- 废弃文档原地标注：双版本共存易误读，否决。

## 回滚

全部迁移保留 git 历史，按 `06-变更记录` 反向 `git mv` 还原；新增的 `docs/README.md`、`04-文档目录规范.md` 删除即可。

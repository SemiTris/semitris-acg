# 00-需求（collection + review）

## 目标

实现收藏/追番与评价后端：collection 增删改、按番查询、连表列表；review 增删改、按番列表；review 写操作**同事务重算** anime.rating。

## 范围

- **只做后端**（Mapper+XML / Service / Controller），前端另行安排。
- 契约以 `docs/03-接口文档/collection.md`、`review.md` 为准，不得自创。
- `review/page`（安利墙最近评价用）**本期不做**，待推荐迭代再实现。

## 功能清单

| 模块 | 接口 | 说明 |
|---|---|---|
| collection | POST `/collection/add` | 同一番剧重复收藏返回失败（唯一约束） |
| collection | DELETE `/collection/delete/{id}` | — |
| collection | PUT `/collection/update` | 只更新非空字段；listType/favorite/progress 校验 |
| collection | GET `/collection/findByAnime/{animeId}` | 详情页判断收藏状态，连表 |
| collection | GET `/collection/list?listType=` | 连表返回 title/cover；listType 不传=全部 |
| review | POST `/review/add` | rating 必填 1~10；写后重算 rating |
| review | PUT `/review/update` | 只更新非空；写后重算 rating |
| review | DELETE `/review/delete/{id}` | 写后重算 rating |
| review | GET `/review/listByAnime/{animeId}` | 该番评价，时间倒序 |

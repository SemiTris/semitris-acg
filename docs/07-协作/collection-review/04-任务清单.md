# 04-任务清单（collection + review）

| 任务ID | 目标 | 涉及文件 | 输入输出 | 验收 |
|---|---|---|---|---|
| C-01 | CollectionMapper + XML（含连表） | `mapper/CollectionMapper.java`、`resources/mapper/CollectionMapper.xml` | 输出：insert/delete/update/selectByAnimeAndUser/listByUser | SQL 连表、动态 set/where、@Mapper |
| C-02 | CollectionService + Impl | `service/CollectionService.java`、`service/impl/CollectionServiceImpl.java` | 输出：add/delete/update/findByAnime/list | 校验、后端填 userId、重复 add 失败不抛异常 |
| C-03 | ReviewMapper + XML + Anime 追加重算 | `mapper/ReviewMapper.java`、`resources/mapper/ReviewMapper.xml`、`mapper/AnimeMapper.java`(+updateAnimeRating)、`resources/mapper/AnimeMapper.xml` | 输出：insert/update/delete/selectByAnimeId/selectById + updateAnimeRating | 重算 SQL 正确 |
| C-04 | ReviewService + Impl | `service/ReviewService.java`、`service/impl/ReviewServiceImpl.java` | 输出：add/update/delete/listByAnime | rating 1~10 校验；@Transactional 同事务重算 |
| C-05 | Controller 两个 | `controller/CollectionController.java`、`controller/ReviewController.java` | 输出：5+4 接口 | 路径/返回对齐契约 |
| C-06 | 联调 | 上述全部 | — | 逐接口跑通 + rating 联动验证 |

## 实现要求

- `CollectionMapper`：`insertCollection`（userId 由 Service 填充）、`deleteCollectionById`、`updateCollection`（动态 `<set>`）、`selectByAnimeAndUser(animeId,userId)`（连表）、`listByUser(userId,listType)`（连表，`ORDER BY id DESC`，listType 可选）。
- `ReviewMapper`：`insertReview`、`updateReview`（动态 set rating/content，不含 anime_id）、`deleteReviewById`、`selectByAnimeId`（`ORDER BY id DESC`）、`selectById`。
- `AnimeMapper` 追加：`updateAnimeRating(animeId)` → `update anime set rating = (select avg(rating) from review where anime_id=#{animeId}) where id=#{animeId}`。
- `ReviewServiceImpl` 写操作：`@Transactional`，完成后调用 `animeMapper.updateAnimeRating(animeId)`（update 时需先 `selectById` 取原 anime_id）。删除时同样先取 anime_id。
- `CollectionServiceImpl`：add 时 try 唯一冲突，捕获后返回 false（或先按 user+anime 查重返回 false）。
- progress 校验：add/update 若传 progress，查询 anime.episodes 校验 `0<=progress<=episodes`。

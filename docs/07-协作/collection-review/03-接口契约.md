# 03-接口契约（collection + review）

接口契约以 `docs/03-接口文档/collection.md`、`review.md` 为准，此处列实现要点。

## collection（基础路径 /collection）

| 方法 | 路径 | 返回 |
|---|---|---|
| POST | `/collection/add` | `R<Void>`（重复收藏返回失败） |
| DELETE | `/collection/delete/{id}` | `R<Void>` |
| PUT | `/collection/update` | `R<Void>`（只更新非空字段） |
| GET | `/collection/findByAnime/{animeId}` | `R<Collection>`（连表；无收藏返回 `R.success(null)`） |
| GET | `/collection/list?listType=` | `R<List<Collection>>`（连表，listType 不传=全部） |

## review（基础路径 /review）

| 方法 | 路径 | 返回 |
|---|---|---|
| POST | `/review/add` | `R<Void>` |
| PUT | `/review/update` | `R<Void>` |
| DELETE | `/review/delete/{id}` | `R<Void>` |
| GET | `/review/listByAnime/{animeId}` | `R<List<Review>>`（时间倒序） |

## 实现要点

- 统一返回 `R<T>`：成功 `R.success(...)`，失败 `R.error("...")`。
- `user_id` 不进请求体；前端传与不传均以后端 `DEFAULT_USER_ID=1L` 覆盖。
- review `update` 不允许变更 `anime_id`（评价归属不可迁移），只更新 rating/content。
- `/collection/findByAnime/{animeId}`：无记录返回 `R.success(null)`（前端靠 data 判空，非错误）。

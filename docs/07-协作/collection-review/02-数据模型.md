# 02-数据模型（collection + review）

数据模型以 `docs/02-技术设计/02-数据库设计.md` 的 `collection`、`review`、`anime` 表为权威。

## collection 表约束

| 字段 | 约束 | 校验（Service 层） |
|---|---|---|
| user_id | NOT NULL | 后端填充 `DEFAULT_USER_ID=1L` |
| anime_id | NOT NULL | 必填；外键存在性由 DB 保证 |
| list_type | 1~5 | 传值须 1~5（1想看 2在看 3已看完 4搁置 5最爱） |
| progress | 0 <= progress <= episodes | 查 anime.episodes 校验上限 |
| favorite | 0/1 | 传值须 0/1 |
| 唯一 | uk_user_anime(user_id, anime_id) | 重复 add → 返回失败（不抛异常） |

## review 表约束

| 字段 | 约束 | 校验 |
|---|---|---|
| user_id | NOT NULL | 后端填充 `DEFAULT_USER_ID=1L` |
| anime_id | NOT NULL | 必填 |
| rating | NOT NULL，1~10 | 必填且须 1~10 |
| content | 可选 | — |

## rating 冗余同步

- `anime.rating = AVG(review.rating)`，review 增/改/删后**同事务**重算。
- 该番无评价时 `rating` 置 NULL。
- DECIMAL(3,1) 自动保留 1 位小数（AVG 超过 10 不会出现，因 rating 已限制 1~10）。

## 连表补充字段（非持久化）

- `Collection` 实体新增非持久化字段 `title`、`cover`（源：anime 表），仅连表查询回填。

# 05-验收标准（collection + review）

## collection

- [ ] POST `/collection/add`：成功后 /collection/list 可见；同番重复 add 返回失败（不抛异常、不 500）。
- [ ] DELETE `/collection/delete/{id}`：删除后列表/按番查询均消失。
- [ ] PUT `/collection/update`：只更新传入字段；listType 非 1~5、favorite 非 0/1、progress 超出 episodes 均拒绝。
- [ ] GET `/collection/findByAnime/{animeId}`：连表返回 title/cover；未收藏返回 200 且 data 为 null。
- [ ] GET `/collection/list?listType=`：连表 title/cover 正确；传 listType 只返回该状态；不传返回全部。

## review 与 rating 联动

- [ ] POST `/review/add`：rating 非 1~10 或缺失返回失败；成功后 anime.rating=该番 AVG（同事务）。
- [ ] PUT `/review/update`：只更新非空（rating/content）；anime_id 不可变更；改后 AVG 重算。
- [ ] DELETE `/review/delete/{id}`：删除后 AVG 重算；删光评价后 anime.rating 为 NULL。
- [ ] GET `/review/listByAnime/{animeId}`：按时间倒序返回。

## 规范

- [ ] 全部接口返回 `R<T>`（code=200/500）；分层 controller→service→mapper 无跨层。
- [ ] 所有查询/插入强制带 `user_id=1` 过滤/填充，前端不感知。
- [ ] 遵循 `docs/05-规范/01-编码规范.md`；后端 `./mvnw spring-boot:run` 正常启动。

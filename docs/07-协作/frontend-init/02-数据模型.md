# 02-数据模型（frontend 前端）

前端不新增数据表，纯展示层。数据均来自后端接口连表结果，对应字段以 `docs/03-接口文档/` 为权威。

## 各页面数据来源

| 页面 | 接口 | 展示字段 |
|---|---|---|
| 卡片墙 | `GET /anime/page` | Anime（title/originalTitle/cover/type/status/rating/year/genre/episodes/synopsis） |
| 编辑弹窗 | `POST /anime/add`、`PUT /anime/update`、`POST /file/upload` | Anime 表单字段 + 封面上传返回 OSS 直链 |
| 详情页 | `GET /anime/findById/{id}`、`GET /collection/findByAnime/{animeId}`、`POST /collection/add|update`、`GET /review/listByAnime/{animeId}`、`POST/DELETE /review/add\|delete|update` | Anime 全字段 + Collection(listType/progress/favorite) + Review 列表 |
| 追番列表 | `GET /collection/list?listType=` | Collection + title/cover（连表） |
| 安利墙 | `GET /recommend/list` | Recommend + title/cover（连表） |

## 枚举展示约定

- `type`：1=动画 2=漫画
- `status`：0=连载中 1=已完结
- `listType`：1=想看 2=在看 3=已看完 4=搁置 5=最爱
- `favorite`：0/1
- `rating`：番剧平均评分显示到 1 位小数（如 9.5）

## 封面

- `cover` 字段为 OSS 公开直链（如 `https://{bucket}.{endpoint}/cover/xxx.jpg`），前端以 `<img :src>` 直用。
- 值为空/加载失败时显示占位图（渐变底 + 站名文案）。

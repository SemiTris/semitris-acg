# 03-接口契约（frontend 前端调用）

前端只调用后端既有契约（`docs/03-接口文档/` 为权威），不自创接口。约定：所有调用经 `utils/request.js`，`code===200` 返回 `data`。

## 接口函数清单（src/api/*.js）

| 模块 | 函数 | 方法+路径 | 备注 |
|---|---|---|---|
| anime | `page(params)` | GET `/anime/page` | params: pageNum/pageSize/title/type/status |
| anime | `list()` | GET `/anime/list` | 下拉数据 |
| anime | `findById(id)` | GET `/anime/findById/{id}` | |
| anime | `add(data)` | POST `/anime/add` | |
| anime | `update(data)` | PUT `/anime/update` | |
| anime | `del(id)` | DELETE `/anime/delete/{id}` | |
| collection | `add(data)` | POST `/collection/add` | |
| collection | `update(data)` | PUT `/collection/update` | |
| collection | `del(id)` | DELETE `/collection/delete/{id}` | |
| collection | `findByAnime(animeId)` | GET `/collection/findByAnime/{animeId}` | 未收藏时 data=null |
| collection | `list(listType)` | GET `/collection/list?listType=` | |
| review | `add(data)` | POST `/review/add` | |
| review | `update(data)` | PUT `/review/update` | |
| review | `del(id)` | DELETE `/review/delete/{id}` | |

| recommend | `add(data)` | POST `/recommend/add` | |

## 页面 ↔ 接口映射

- **卡片墙**：`anime.page`（列表/搜索/筛选）+ 删除 `anime.del`。
- **编辑弹窗**：新增→`file.upload`（选封面上传得直链）+ `anime.add`；编辑→`file.upload`（可选）+ `anime.update`。
- **详情页**：`anime.findById` + `collection.findByAnime`（判断收藏状态）+ `collection.add/update/delete` + `review.listByAnime` + `review.add/update/delete`。
- **追番列表**：`collection.list(listType)`（切换 tab 再查）+ `collection.update`（改进度/状态）。
- **安利墙**：`recommend.list`。

## 入参约定

- 时间字段（createdAt/updatedAt）前端不传；`userId` 前端不传（后端固定 1）。
- `collection.update`/`review.update`/`recommend.update` 只传需变更的非空字段 + id。

# 00-需求（frontend 前端工程与页面）

## 目标

搭建 `frontend/` 前端工程（Vue3 + Element Plus + Vite），二次元暗色主题，完成全部页面并对接后端六大模块接口，数据不写死。

## 范围

- **本期**：初始化工程 + 公共层（axios 封装 / 路由 / 布局 / 主题）+ 全部页面。
- **后置**：`/login` 登录页（user 模块 M4 可选，本期不做）。
- 调用接口一律以后端既有契约为准（`docs/03-接口文档/`），不自创接口。

## 页面清单

| 页面 | 路由 | 功能 |
|---|---|---|
| 番剧卡片墙 | `/anime` | 分页列表 + 标题搜索 + 类型/状态筛选 + 新增/编辑/删除入口 |
| 番剧编辑弹窗 | — | 新增/编辑表单（含封面上传，OSS 直链入 cover） |
| 番剧详情页 | `/anime/:id` | 简介 + 收藏状态与操作 + 评价列表 + 写评价 |
| 追番列表页 | `/collection` | 按收藏类型展示 + 更新进度/状态 |
| 安利墙 | `/recommend` | 推荐卡片列表（番剧信息 + 理由 + 标签） |

## 非功能

- 二次元暗色主题（品牌基调见 `docs/00-项目定义/00-命名与品牌.md`）。
- 无封面时显示占位图，卡片不破版。
- 请求统一拦截 `R<T>`：`code=200` 取 `data`，否则弹出 `message`。

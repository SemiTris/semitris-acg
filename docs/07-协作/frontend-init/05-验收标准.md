# 05-验收标准（frontend 前端）

## 工程与公共层

- [ ] `npm run dev` 启动成功；`/api` 经 vite proxy 可达后端 8080，无跨域问题。
- [ ] 项目可 `npm run build` 通过。
- [ ] 二次元暗色主题统一生效（深底 `#1a1a2e`、主粉 `#ff9ac1`、辅紫 `#a29bfe`、正文 `#e6e6ef`），卡片 hover 上浮微渐变。
- [ ] `request.js` 拦截生效：`code===200` 页面拿 data；业务失败弹出 message 且不 500 崩溃。

## 页面

- [ ] **卡片墙**：分页正确；标题搜索、type/status 筛选正确；数据来自 `/anime/page`。
- [ ] **编辑弹窗**：新增/编辑；title 必填校验、type/status 枚举限制；封面上传返回 OSS 直链并回显；`anime.add/update` 正常。
- [ ] **删除**：二次确认后调用 `anime.del`，列表刷新。
- [ ] **详情页**：显示简介/评分/年份等；收藏状态正确（未收藏可收藏、已收藏可改状态/进度/取消）；评价可写/改/删，列表展示；评分联动（后端重算）页面刷新可见。
- [ ] **追番列表**：listType 切换过滤正确；进度/状态更新生效。
- [ ] **安利墙**：show 番剧 title/cover + 理由 + 标签。

## 数据与规范

- [ ] 页面数据均来自真实接口，无硬编码；接口调用对齐 `docs/03-接口文档/`。
- [ ] 无封面时显示占位图，卡片不破版。
- [ ] 时间字段与 userId 不传；update 类只传变更字段 + id。

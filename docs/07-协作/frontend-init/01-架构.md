# 01-架构（frontend 前端工程）

## 技术栈（权威见 docs/02-技术设计/00-技术选型.md）

Vue 3（Composition API，`<script setup>`）+ Element Plus + Vite + axios + vue-router。工程根即 `frontend/`（package.json name=semitris-acg-web）。

## 目录结构

```
frontend/
├── index.html
├── vite.config.js       # @ 别名 + dev proxy /api → http://localhost:8080
├── package.json
├── src/
│   ├── main.js          # 挂载 Element Plus（暗色主题）与 router
│   ├── App.vue          # 根组件（布局 slot）
│   ├── theme/           # CSS 变量 + Element Plus 暗色覆盖
│   │   ├── variables.css   # 品牌色板（深底/粉/紫/文字）
│   │   └── element-override.css
│   ├── utils/request.js # axios 实例 + R<T> 拦截
│   ├── api/             # 按模块封装接口函数
│   │   ├── anime.js / collection.js / review.js / recommend.js / file.js / user.js
│   ├── router/index.js  # 路由表 + 布局
│   ├── layout/          # 顶栏导航 + 主内容区
│   │   └── MainLayout.vue
│   ├── components/      # 通用组件
│   │   ├── AnimeCard.vue     # 卡片（封面/标题/评分/状态）
│   │   ├── CoverImage.vue    # 封面 + 无图兜底占位
│   │   ├── StatusTag.vue     # 连载状态/收藏类型标签

```

## 关键约定

- **请求封装**（`utils/request.js`）：`baseURL='/api'` + vite proxy 转发 `http://localhost:8080`；响应拦截：`code===200` 直接返回 `data`，否则 `ElMessage.error(message)` 并 reject（业务失败统一提示、不写死页面数据）。
- **主题**：CSS 变量定义色板（背景 `#1a1a2e`、主粉 `#ff9ac1`、辅紫 `#a29bfe`、正文 `#e6e6ef`）；Element Plus 深色模式覆盖 + 卡片 hover 上浮微渐变。
- **封面**：`anime.cover/review.cover/recommend.cover` 均为 OSS 直链 URL，直接 `<img :src>`；`CoverImage` 组件处理加载失败/空值 → 占位图（渐变底 + 文案），不破版。

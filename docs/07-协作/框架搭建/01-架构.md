# 01-架构（框架搭建：目标目录结构）

> **已被取代（superseded）**：本包记录的目录结构已在 ADR-0002（`docs/06-记录/adr/0002-文档目录整合与统一规范.md`）中整合，最终以 `docs/05-规范/04-文档目录规范.md` 为准。以下内容仅作历史参考。

## 顶层布局（目标态）

```
semitris-acg/
├── AGENTS.md            # 项目级 AI 协作约定（OpenCode 自我初始化产物）
├── README.md / LICENSE
├── .gitignore           # 根级忽略规则
├── docs/                # 全部文档（原顶层 00~05 目录 + 设计可视化 整体迁入）
│   ├── 00-项目定义/
│   ├── 01-需求/
│   ├── 02-技术设计/
│   ├── 03-接口文档/
│   ├── 04-计划/
│   ├── 05-规范/
│   ├── 设计可视化/      # 数据库设计可视化 HTML
│   ├── adr/             # 架构决策记录（NNNN-标题.md）
│   └── agent/           # AI 协作设计包（<功能>/00-需求 ~ 06-变更记录）
├── database/            # 数据库脚本（唯一入口 database/init.sql）
├── backend/             # Spring Boot 后端（com.semitris.acg）
└── frontend/            # Vue 前端（semitris-acg-web，待建，仅 README 占位）
```

## 设计原则

1. **单一职责目录**：docs 只管文档、database 只管 SQL、backend/frontend 代码与资源。
2. **文档分级**：`docs/00~05` 为需求/设计正文；`docs/adr` 记录关键决策；`docs/agent` 承载 AI 协作设计包，二者不入正文，避免混淆。
3. **保留历史**：用 `git mv` 迁移，rename 记录可追溯。
4. **契约不变**：仅移动文件位置，数据库、接口、分层、命名均维持 `docs/02-技术设计/`、`docs/03-接口文档/` 的既有约定。

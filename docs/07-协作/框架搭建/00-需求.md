# 00-需求（框架搭建）

## 背景

项目为「烂尾工程」：文档齐全、后端仅有 User 模块完整实现，核心业务模块（anime/collection/review/recommend/file）为空白，且顶层目录未按前后端分离/数据库/docs 的标准布局组织。

## 需求

1. **R1 目录结构标准化**：按前后端分离 + database + docs 的标准开发布局重构顶层目录，保留 git 历史。
2. **R2 AI 协作初始化**：生成项目级 `AGENTS.md`，固化「OpenCode 设计/评审 + Claude Code 实现」的协作契约，使双方 AI（含未来新会话）开工前能自行初始化。
3. **R3 版本库延续**：git 已存在，不做 git init，本次改动走正常提交，随后推送远程更新。

## 本阶段边界（搭框架）

- 只做目录/文档级重构与占位，**不写业务代码**。
- 数据库 schema、接口契约**一律不变**（只迁移文件位置）。
- 前端不建工程，仅放 `frontend/README.md` 占位。

# 02-数据模型（anime）

数据模型以 `docs/02-技术设计/02-数据库设计.md` 的 `anime` 表为唯一权威。

## 关键字段与校验（Service 层入参校验）

| 字段 | 约束 | 校验 |
|---|---|---|
| title | 必填 | 非 null 非空 |
| type | TINYINT，1=动画 2=漫画 | 仅 1/2 |
| status | TINYINT，0=连载 1=完结 | 仅 0/1 |
| rating | DECIMAL(3,1) 0.0~10.0 | 冗余字段，由 review 重算，不入库直接提交 |
| episodes | INT >= 0 | >=0 |

- 删除靠外键 `ON DELETE CASCADE`，Service 不手工删子表。
- snake_case ↔ camelCase 由 `map-underscore-to-camel-case` 自动映射。

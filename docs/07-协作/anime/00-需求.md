# 00-需求（anime 番剧库）

## 目标

实现番剧/漫画资料库：完整 CRUD + 全量列表 + 多条件分页搜索。

## 范围

- **只做后端**（Mapper+XML / Service / Controller），前端迭代另行安排。
- 契约以 `docs/03-接口文档/anime.md` 为准，不得自创。

## 功能清单

| 功能 | 接口 | 说明 |
|---|---|---|
| 新增 | POST `/anime/add` | 标题必填，type/status 枚举校验 |
| 删除 | DELETE `/anime/delete/{id}` | 外键级联清理 collection/review/recommend |
| 修改 | PUT `/anime/update` | 只更新非空字段 |
| 详情 | GET `/anime/findById/{id}` | 单条全部字段 |
| 全量列表 | GET `/anime/list` | 下拉框用，id 倒序 |
| 分页搜索 | GET `/anime/page` | title 模糊 + type/status 等值，可组合 |

# 04-任务清单（anime）

| 任务ID | 目标 | 涉及文件 | 输入输出 | 验收 |
|---|---|---|---|---|
| A-01 | Mapper 接口 + XML | `mapper/AnimeMapper.java`、`resources/mapper/AnimeMapper.xml` | 输入：无；输出：6 个方法 | 方法齐全，SQL 符合编码规范 |
| A-02 | Service 接口 + 实现 | `service/AnimeService.java`、`service/impl/AnimeServiceImpl.java` | 输出：add/delete/update/findById/list/page | 入参校验、PageHelper 分页 |
| A-03 | Controller | `controller/AnimeController.java` | 输出：6 个接口 | 路径/返回 R<T> 与契约一致 |
| A-04 | 联调 | 上述全部 | — | Postman 逐条跑通 |

## 实现要求

- `AnimeMapper.java` 加 `@Mapper` 注解，方法签名对齐 UserMapper。
- XML 内：`insert`（id 自增、时间列默认）、`delete`、`update`（动态 `<set>`）、`selectById`、`selectByCondition`（`<where>`+`<if>`、`LIKE CONCAT`）、`list`（`ORDER BY id DESC`）。
- 分页搜索接口的标题/类型/状态为可选参数，条件全空 = 查全部。
- `rating` 不接受前端提交值（冗余字段，由 review 重算）。

# 03-接口契约（anime）

接口契约以 `docs/03-接口文档/anime.md` 为准，此处仅列实现要点。

## 接口总览

| 方法 | 路径 | 返回值 |
|---|---|---|
| POST | `/anime/add` | `R<Void>` |
| DELETE | `/anime/delete/{id}` | `R<Void>` |
| PUT | `/anime/update` | `R<Void>` |
| GET | `/anime/findById/{id}` | `R<Anime>` |
| GET | `/anime/list` | `R<List<Anime>>`（id 倒序） |
| GET | `/anime/page` | `R<PageInfo<Anime>>` |

## 分页搜索参数（/anime/page）

| 参数 | 默认 | 匹配 |
|---|---|---|
| pageNum | 1 | — |
| pageSize | 5 | — |
| title | — | 模糊 LIKE |
| type | — | 等值（1/2） |
| status | — | 等值（0/1） |

## 实现要点

- 统一返回 `R<T>`：成功 `R.success(...)`，失败 `R.error("...")`。
- 分页用 PageHelper，Service 内 `PageHelper.startPage` + `return new PageInfo<>(list)`。

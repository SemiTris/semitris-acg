# 01-架构（anime 番剧库）

## 分层与依赖

沿用 `docs/02-技术设计/01-架构设计.md`：controller → service(impl) → mapper + XML，禁止跨层。

## 实现样板

参照既有 **User 模块**（`backend/src/main/java/com/semitris/acg/`）落地，逐层把 User 替换为 Anime：

```
controller/AnimeController.java    → 参照 UserController
service/AnimeService.java          → 参照 UserService
service/impl/AnimeServiceImpl.java → 参照 UserServiceImpl
mapper/AnimeMapper.java            → 参照 UserMapper（加 @Mapper）
resources/mapper/AnimeMapper.xml   → 参照 UserMapper.xml
```

- 实体 `entity/Anime.java` 已存在，勿改字段。
- 时间列（created_at/updated_at）走数据库默认值，不在 XML 里手工写。

# 05-验收标准（anime）

## 接口

- [ ] POST `/anime/add`：缺 title 返回失败；type 非 1/2、status 非 0/1 拒绝。
- [ ] DELETE `/anime/delete/{id}`：成功返回 200；删除后其 collection/review/recommend 被级联清理。
- [ ] PUT `/anime/update`：只更新传入字段，空字段不动。
- [ ] GET `/anime/findById/{id}`：返回该番全部字段。
- [ ] GET `/anime/list`：全量，id 倒序。
- [ ] GET `/anime/page`：分页正确；title 模糊、type/status 等值可任意组合，全空 = 全量。

## 规范

- [ ] 全部返回 `R<T>`，`code=200/500`，message 语义清晰。
- [ ] 分层 controller → service → mapper，无跨层注入。
- [ ] 代码遵循 `docs/05-规范/01-编码规范.md`。
- [ ] 后端 `./mvnw spring-boot:run` 正常启动，无 SQL 冲突。

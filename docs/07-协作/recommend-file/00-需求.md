# 00-需求（recommend + file + review/page）

## 目标

1. 安利墙后端：recommend 增删改查（连表返回番剧 title/cover）。
2. 补做 `review/page`（安利墙「最近评价」用，连表）。
3. 封面上传/回显：`file` 上传到本地目录、下载回显，可直接作 `<img src>`。

## 范围

- **只做后端**；前端主题、封面选图、安利墙页面另行安排。
- recommend 契约以 `docs/03-接口文档/recommend.md` 为准；`review/page` 为本包补做（原 collection-review 包范围声明）。
- file 契约以 `docs/03-接口文档/file.md` 为准。

## 功能清单

| 模块 | 接口 | 说明 |
|---|---|---|
| recommend | POST `/recommend/add` | animeId 必填，reason/tags 可选 |
| recommend | PUT `/recommend/update` | 只更新非空；animeId 不可变更 |
| recommend | DELETE `/recommend/delete/{id}` | — |
| recommend | GET `/recommend/list` | 连表 title/cover，id 倒序 |
| review | GET `/review/page` | 分页全量/按番，连表 title/cover（补做） |
| file | POST `/file/upload` | multipart，参数名 file；返回可访问 URL |
| file | GET `/file/download/{filename}` | 图片流回显 |

# 02-数据模型（recommend + file + review/page）

## recommend 表约束（权威见 docs/02-技术设计/02-数据库设计.md）

| 字段 | 约束 | 校验（Service 层） |
|---|---|---|
| user_id | NOT NULL | 后端填充 `DEFAULT_USER_ID=1L` |
| anime_id | NOT NULL | 必填；外键存在性由 DB 保证 |
| reason | VARCHAR(255) 可选 | — |
| tags | VARCHAR(100) 可选 | — |
| 唯一 | 无（同番可多次推荐，契约未禁止） | — |

## file（云存储，无表）

- 存储：阿里云 OSS bucket（`oss.bucket-name`），图片 object 放 `cover/` 前缀。
- 命名：`cover/{时间戳}.{扩展名小写}`，如 `cover/1690000000000.jpg`（无中文/空格，避免签名/回显问题）。
- 公开访问 URL：`https://{bucket}.{endpoint}/{objectName}`（bucket 对外公开读，供 `<img src>` 直链）。
- 依赖：`com.aliyun.oss:aliyun-sdk-oss:3.17.4`（含 Java 9 所需 jaxb 三件套）。

## review 连表补充字段（非持久化）

- `Review` 实体新增非持久化字段 `title`、`cover`（源：anime 表），仅 `/review/page` 连表查询回填；不影响 insert/update。

## 运行期配置（密钥不入库）

- 本地 `application.yaml`（.gitignore 排除）填写真实 `oss.*`；代码仓库仅保存 `application.example.yaml` 模板。

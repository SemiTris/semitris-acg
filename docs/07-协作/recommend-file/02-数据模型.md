# 02-数据模型（recommend + file + review/page）

## recommend 表约束（权威见 docs/02-技术设计/02-数据库设计.md）

| 字段 | 约束 | 校验（Service 层） |
|---|---|---|
| user_id | NOT NULL | 后端填充 `DEFAULT_USER_ID=1L` |
| anime_id | NOT NULL | 必填；外键存在性由 DB 保证 |
| reason | VARCHAR(255) 可选 | — |
| tags | VARCHAR(100) 可选 | — |
| 唯一 | 无（同番可多次推荐，契约未禁止） | — |

## file（无表，磁盘存储）

- 保存目录：`D:/upload/`（`semitris.upload.dir`），结尾必须带 `/`。
- 命名：`System.currentTimeMillis() + 原扩展名（小写）`，如 `1690000000000.jpg`。
- 类型：图片回显（无强制白名单，接口未限定；超大/空文件由 multipart 配置与判空拦截）。

## review 连表补充字段（非持久化）

- `Review` 实体新增非持久化字段 `title`、`cover`（源：anime 表），仅 `/review/page` 连表查询回填；不影响 insert/update。

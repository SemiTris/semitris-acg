| R-07 | 联调 | 上述全部 | — | 逐接口 HTTP 验证 |

## 实现要求

- `RecommendMapper.xml` 的 `list` 用 `LEFT JOIN anime` 取 `title/cover`，映射到实体非持久化字段；`ORDER BY id DESC`。
- `updateRecommend` 动态 `<set>` 仅含 reason/tags（不含 anime_id/user_id）；Service 判无可更新字段拒绝。
- `review/page` 连表 SQL：`select r.*, a.title, a.cover from review r left join anime a on r.anime_id=a.id` + 可选 `where r.anime_id=#{animeId}` + `order by r.id desc`（PageHelper 分页）。
- `OssUtil`：`@Component`，`@Value` 注入 `oss.*`；`upload(objectName, InputStream)` 用 `OSSClientBuilder` 流式 putObject，返回 `https://{bucket}.{endpoint}/{objectName}`。
- `FileController`：`@PostMapping("/upload")` 接收 `MultipartFile file`（参数名 file）；空 → `R.error("文件为空")`；objectName = `cover/{时间戳}.{小写扩展名}`；`ossUtil.upload(...)` 返回 `R.success("上传成功", url)`；配置缺失（键为空）→ `R.error("上传服务未配置")`。
- `pom.xml` 新增：`com.aliyun.oss:aliyun-sdk-oss:3.17.4` + `javax.xml.bind:jaxb-api:2.3.1` / `javax.activation:activation:1.1.1` / `org.glassfish.jaxb:jaxb-runtime:2.3.3`。
- `application.example.yaml`：完整配置模板（含 oss.* 空键），提交入库；真实 `application.yaml` 由开发者复制模板填写，不入库。
- `backend/.gitignore` 追加 `src/main/resources/application.yaml`，并 `git rm --cached` 解除既有跟踪。

# 04-任务清单（recommend + file + review/page）

| 任务ID | 目标 | 涉及文件 | 输入输出 | 验收 |
|---|---|---|---|---|
| R-01 | RecommendMapper + XML | `mapper/RecommendMapper.java`（@Mapper）、`resources/mapper/RecommendMapper.xml` | 输出：insert/delete/update/list（连表） | 方法齐全，list 连表 title/cover |
| R-02 | RecommendService + Impl | `service/RecommendService.java`、`service/impl/RecommendServiceImpl.java` | 输出：add/delete/update/list | userId 填充、animeId 必填、update 不可改 animeId、无可更新字段拒绝 |
| R-03 | RecommendController | `controller/RecommendController.java` | 输出：4 接口 | 路径/返回对齐契约 |
| R-04 | review/page 补做 | `entity/Review.java`（+title/cover）、`mapper/ReviewMapper.java/+XML`（+listByPage 连表）、`service/ReviewService.java/+Impl`（+pageReview）、`controller/ReviewController.java`（+/page） | 输出：分页连表接口 | PageInfo 正确、可选 animeId、倒序、连表字段 |
| R-05 | File 上传/回显 | `controller/FileController.java`、`application.yaml`（+multipart 配置） | 输出：upload/download | 上传返回完整 URL、下载可 `<img src>`、空文件拒绝、路径穿越防护 |
| R-06 | 联调 | 上述全部 | — | 逐接口 HTTP 验证 |

## 实现要求

- `RecommendMapper.xml` 的 `list` 用 `LEFT JOIN anime` 取 `title/cover`，映射到实体非持久化字段；`ORDER BY id DESC`。
- `updateRecommend` 动态 `<set>` 仅含 reason/tags（不含 anime_id/user_id）；Service 判无可更新字段拒绝。
- `review/page` 连表 SQL：`select r.*, a.title, a.cover from review r left join anime a on r.anime_id=a.id` + 可选 `where r.anime_id=#{animeId}` + `order by r.id desc`（PageHelper 分页）。
- FileController：`@PostMapping("/upload")` 接收 `MultipartFile file`（参数名 file），空 → `R.error("文件为空")`；目录不存在则 `mkdirs`；文件名 = `System.currentTimeMillis()` + 扩展名（小写）；返回 `http://localhost:8080/file/download/{filename}`。
- FileController：`@GetMapping("/download/{filename}")` 用 `ResponseEntity<Resource>` 返回图片流，Content-Type 按扩展名；防路径穿越（仅取 basename，不允许 `..`）。
- `application.yaml` 增配：`spring.servlet.multipart.max-file-size: 10MB`、`max-request-size: 10MB`。

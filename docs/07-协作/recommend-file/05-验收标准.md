# 05-验收标准（recommend + file + review/page）

## recommend

- [ ] POST `/recommend/add`：缺 animeId 拒绝；成功后 /recommend/list 可见（连表 title/cover）。
- [ ] DELETE `/recommend/delete/{id}`：删除后列表消失。
- [ ] PUT `/recommend/update`：只更新传入字段；animeId 不可变更；仅传 id（无可更新字段）返回失败。
- [ ] GET `/recommend/list`：连表 title/cover 正确，按 id 倒序。

## review/page（补做）

- [ ] GET `/review/page`：默认 pageNum=1/pageSize=5，总条数正确；`animeId=1` 只返回该番评价。
- [ ] 连表 title/cover 正确，按 id 倒序。

## file

- [ ] POST `/file/upload`（multipart 字段名 file）：成功返回完整 URL；空文件返回 `R.error`。
- [ ] 文件实际落盘 `D:/upload/`，文件名时间戳+扩展名，无中文/空格。
- [ ] GET `/file/download/{filename}`：浏览器/`<img src>` 直接显示图片。
- [ ] 下载路径穿越防护：带 `..` 的非法文件名不越目录。

## 规范

- [ ] 全部接口返回 `R<T>`（code=200/500）；分层 controller→service→mapper（file 除外，无 Mapper）。
- [ ] 遵循 `docs/05-规范/01-编码规范.md`；后端 `./mvnw spring-boot:run` 正常启动。

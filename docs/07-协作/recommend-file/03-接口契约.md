# 03-接口契约（recommend + file + review/page）

接口契约以 `docs/03-接口文档/recommend.md`、`file.md` 与 `review.md` 为准，此处列实现要点。

## recommend（基础路径 /recommend）

| 方法 | 路径 | 返回 |
|---|---|---|
| POST | `/recommend/add` | `R<Void>` |
| PUT | `/recommend/update` | `R<Void>`（仅 non-null 字段；animeId 不可变更） |
| DELETE | `/recommend/delete/{id}` | `R<Void>` |
| GET | `/recommend/list` | `R<List<Recommend>>`（连表 title/cover，id 倒序） |

## review/page（本包补做）

| 方法 | 路径 | 返回 |
|---|---|---|
| GET | `/review/page` | `R<PageInfo<Review>>`（连表 title/cover，id 倒序） |

参数：`pageNum`（默认1）/ `pageSize`（默认5）/ `animeId`（可选，仅返回该番评价）。

## file（基础路径 /file）

| 方法 | 路径 | 返回 |
|---|---|---|
| POST | `/file/upload` | `R<String>`（data=OSS 公开 URL） |
| GET | `/file/download/{filename}` | **弃用**（OSS 直链，无本地回显） |

- upload 表单字段名必须为 `file`（multipart）。
- 上传成功返回：`{ "code": 200, "message": "上传成功", "data": "https://bucket.endpoint/cover/1690000000000.jpg" }`（OSS 直链，可作 `<img src>`）。
- 空文件：返回 `R.error("文件为空")`；未配置 OSS 密钥：返回 `R.error("上传服务未配置")`。

## 实现要点

- 统一返回 `R<T>`；recommend/review/page 遵循既有分层；file 不涉及 DB 分层。
- update 无可更新字段（reason/tags 均空）→ 返回失败（避免动态 SQL 空 set）。
- `/file/download` 不在 FileController 实现（弃用）；前端的封面展示使用 anime.cover 的 OSS 直链。

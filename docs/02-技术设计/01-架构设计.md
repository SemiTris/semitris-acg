# 01-架构设计

## 1. 整体架构：前后端分离

```
浏览器（Vue 前端 semitris-acg-web）
   │  axios 调用（JSON，CORS 全开）
   ▼
Spring Boot 后端（默认 8080）  com.semitris.acg
   ├─ controller 层   —— 接收请求 / 响应，统一 R<T>
   ├─ service 层      —— 业务逻辑（接口 + impl）
   ├─ mapper 层       —— MyBatis 接口 + XML
   └─ entity 层       —— 数据库表实体
   │
   ▼
MySQL（semitris_acg）  ＋  阿里云 OSS（封面云存储）
```

## 2. 技术选型（权威见 [00-技术选型.md](00-技术选型.md)）

| 项 | 选择 | 版本 |
|---|---|---|
| 语言 | Java | 17 |
| 框架 | Spring Boot | 3.5.16 |
| 持久层 | MyBatis（XML 方式） | mybatis-spring-boot-starter 3.0.5 |
| 分页 | PageHelper | pagehelper-spring-boot-starter 2.1.1 |
| 数据库 | MySQL | 8.x（utf8mb4） |
| 认证 | 简单登录（BCrypt，不返回 token） | spring-security-crypto |
| 工具 | Lombok / Maven | — |
| 前端 | Vue 3（Composition API） | — |
| UI 组件 | Element Plus | 最新稳定版 |
| 构建工具 | Vite | 最新稳定版 |

> **刻意不加 MyBatis-Plus / JPA** —— 保持 SQL 透明可控，ORM 仅作映射边界。

## 3. 后端包结构

```
com.semitris.acg
├── SemitrisAcgApplication.java    启动类
├── controller/
│   ├── AnimeController.java
│   ├── CollectionController.java
│   ├── ReviewController.java
│   ├── RecommendController.java
│   ├── UserController.java
│   └── FileController.java
├── service/                       业务接口
│   └── impl/                      业务实现
├── mapper/                        MyBatis 接口
├── entity/                        实体类
├── config/                        CorsConfig 等
├── util/                          R.java、MD5Util.java、文件工具等
└── resources/
    ├── application.yaml
    └── mapper/*.xml               SQL 映射
```

## 4. 分层职责与依赖方向

- `controller → service → mapper`，禁止跨层直接访问。
- 所有响应经 `R<T>` 包装，controller 不直接返回裸对象。
- 每张表一个 Mapper 接口 + 一个 XML（`classpath:mapper/*.xml`）。
- 分页由 Service 层调用 PageHelper 后返回 `PageInfo`。

## 5. 关键配置（application.yaml 要点）

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/semitris_acg
    username: root
    password: root

mybatis:
  configuration:
    log-impl: org.apache.ibatis.logging.commons.JakartaCommonsLoggingImpl
    map-underscore-to-camel-case: true
  mapper-locations: classpath:mapper/*.xml
  type-aliases-package: com.semitris.acg.entity

pagehelper:
  reasonable: true

# 阿里云 OSS 封面云存储（真实密钥只填本地 application.yaml；仓库仅存 application.example.yaml 模板）
oss:
  endpoint:              # Bucket 所在地域 Endpoint
  access-key-id:         # AccessKey ID
  access-key-secret:     # AccessKey Secret
  bucket-name:           # Bucket 名称
```

- 端口默认 `8080`，若端口占用则修改 `server.port`。
- CORS 全开（已实现于 `util/CorsConfig`：所有 origin、GET/POST/PUT/DELETE/OPTIONS）。

## 6. 前端规划（后续阶段）

- 工程名：`semitris-acg-web`（Vite 脚手架，位于 `frontend/`）。
- axios 封装统一请求，拦截 `R<T>`：`code=200` 取 data，否则弹出 message。
- 路由：`/anime`、`/anime/:id`、`/collection`、`/recommend`、`/login`。
- 组件：番剧卡片、分页器、表单弹窗、封面上传、状态标签。

## 7. 实现约定

> 每一模块按既有模板一致落地：controller → service(impl) → mapper + XML 分层实现；User 模块已形成可复用样板（`UserController → UserServiceImpl → UserMapper → UserMapper.xml`），其余模型按相同模式扩展实现，不做跨层直连。

# 00-技术选型（权威）

> **本文档为技术栈唯一权威。**

## 技术栈总表

| 层 | 技术 | 版本 | 说明 |
|---|---|---|---|
| 后端语言 | Java | 17 | Java 企业级事实标准 |
| 后端框架 | Spring Boot | 3.5.16 | 自动配置开箱即用 |
| ORM | 原生 MyBatis + PageHelper | mybatis-spring-boot-starter 3.0.5 / pagehelper-spring-boot-starter 2.1.1 | SQL 透明可控，PageHelper 一行搞定分页；**刻意不用 MyBatis-Plus / JPA**（保持 SQL 可控、ORM 仅作映射） |
| 数据库 | MySQL | 8.x（utf8mb4） | 最主流关系型数据库 |
| 认证 | 简单登录（**BCrypt** 加密，不返回 token） | spring-security-crypto | 聚焦业务，不做复杂权限体系；**禁止 MD5**，库列宽 VARCHAR(64) |
| 前端语言 | JavaScript | — | Vue 生态默认使用 |
| 前端框架 | Vue | 3（Composition API） | 渐进式框架，简洁高效 |
| UI 组件 | Element Plus | 最新稳定版 | Vue3 生态最成熟组件库，表格/表单/弹窗开箱即用 |
| 构建工具 | Vite | 最新稳定版 | 秒级冷启动，开发体验极佳 |

## 说明

- **前端工程**：`frontend/` 下创建 `semitris-acg-web`（Vite 脚手架），路由 `/anime` `/anime/:id` `/collection` `/recommend` `/login`。
- **接口契约不变**：调用 `docs/03-接口文档/`，统一 `R<T>`，数据不写死。
- **认证为可后置项**（第二迭代）：单人站点可先用 `DEFAULT_USER_ID=1L` 固定用户；登录实现时按 `docs/03-接口文档/user.md` + `PasswordUtil.matches`（BCrypt）落地。
- **前后端解耦**：接口与前端组件无关，后续若换 UI 库，后端零改动。

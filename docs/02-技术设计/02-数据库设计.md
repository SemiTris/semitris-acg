# 02-数据库设计

> ⚠️ **已废弃**：本文档已被 [02-数据库设计_优化版.md](./02-数据库设计_优化版.md) 取代。
> 数据库设计以优化版为准，可执行脚本见 `database/init.sql`。本文件仅供历史参考。

## 1. 总览

- 库名：`semitris_acg`，字符集 utf8mb4。
- 共 **5 张表**：`user` / `anime` / `collection` / `review` / `recommend`。
- 关系：以 `anime` 为中心，`collection` / `review` / `recommend` 通过外键指向 `anime`。
- 字段一律 snake_case，代码字段 camelCase（`map-underscore-to-camel-case: true`）。

## 2. 表关系（文字版 ER）

```
user ──── (单人简化，暂不关联业务表)

anime ──── (1 : 0..1) ──── collection   一部番最多一条收藏记录
anime ──── (1 : 0..*) ──── review       一部番可有多个评价
anime ──── (1 : 0..*) ──── recommend    一部番可有多次推荐
```

## 3. 建库

```sql
CREATE DATABASE IF NOT EXISTS semitris_acg DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE semitris_acg;
```

## 4. 表结构与 DDL

### 4.1 user 用户表

```sql
CREATE TABLE `user` (
    id            BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键',
    username      VARCHAR(50)  NOT NULL COMMENT '账号',
    password      VARCHAR(64)  NOT NULL COMMENT '密码（MD5 加密后存储）',
    nickname      VARCHAR(50)  DEFAULT NULL COMMENT '昵称',
    avatar        VARCHAR(255) DEFAULT NULL COMMENT '头像 URL',
    register_time DATETIME     DEFAULT CURRENT_TIMESTAMP COMMENT '注册时间',
    PRIMARY KEY (id),
    UNIQUE KEY uk_username (username)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表（单人站点，先简化）';
```

### 4.2 anime 番剧/漫画表

```sql
CREATE TABLE `anime` (
    id             BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键',
    title          VARCHAR(100) NOT NULL COMMENT '中文标题',
    original_title VARCHAR(100) DEFAULT NULL COMMENT '原名',
    cover          VARCHAR(255) DEFAULT NULL COMMENT '封面图片 URL',
    type           TINYINT      DEFAULT 1 COMMENT '类型：1=动画 2=漫画',
    genre          VARCHAR(100) DEFAULT NULL COMMENT '类型标签，逗号分隔，如：热血,奇幻',
    episodes       INT          DEFAULT 0 COMMENT '集数/话数',
    status         TINYINT      DEFAULT 0 COMMENT '连载状态：0=连载中 1=已完结',
    year           INT          DEFAULT NULL COMMENT '播出/连载年份',
    rating         DECIMAL(2,1) DEFAULT NULL COMMENT '我的平均评分（0.0 ~ 10.0）',
    synopsis       TEXT         COMMENT '简介',
    created_at     DATETIME     DEFAULT CURRENT_TIMESTAMP COMMENT '录入时间',
    PRIMARY KEY (id),
    KEY idx_type (type),
    KEY idx_title (title)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='番剧/漫画资料表';
```

### 4.3 collection 收藏/追番表

```sql
CREATE TABLE `collection` (
    id         BIGINT   NOT NULL AUTO_INCREMENT COMMENT '主键',
    anime_id   BIGINT   NOT NULL COMMENT '番剧 ID',
    list_type  TINYINT  DEFAULT 1 COMMENT '收藏类型：1=想看 2=在看 3=已看完 4=搁置 5=最爱',
    progress   INT      DEFAULT 0 COMMENT '看到第几集/话',
    favorite   TINYINT  DEFAULT 0 COMMENT '是否加精收藏：0=否 1=是',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '收藏时间',
    PRIMARY KEY (id),
    UNIQUE KEY uk_anime (anime_id),
    CONSTRAINT fk_collection_anime FOREIGN KEY (anime_id) REFERENCES anime (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='收藏/追番表';
```

### 4.4 review 评价表

```sql
CREATE TABLE `review` (
    id         BIGINT   NOT NULL AUTO_INCREMENT COMMENT '主键',
    anime_id   BIGINT   NOT NULL COMMENT '番剧 ID',
    rating     INT      NOT NULL COMMENT '评分（1 ~ 10）',
    content    TEXT     COMMENT '评价内容',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '评价时间',
    PRIMARY KEY (id),
    KEY idx_anime (anime_id),
    CONSTRAINT fk_review_anime FOREIGN KEY (anime_id) REFERENCES anime (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='评价表';
```

### 4.5 recommend 推荐表

```sql
CREATE TABLE `recommend` (
    id         BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键',
    anime_id   BIGINT       NOT NULL COMMENT '番剧 ID',
    reason     VARCHAR(255) DEFAULT NULL COMMENT '推荐理由',
    tags       VARCHAR(100) DEFAULT NULL COMMENT '推荐标签，如：治愈,神作',
    created_at DATETIME     DEFAULT CURRENT_TIMESTAMP COMMENT '推荐时间',
    PRIMARY KEY (id),
    KEY idx_anime (anime_id),
    CONSTRAINT fk_recommend_anime FOREIGN KEY (anime_id) REFERENCES anime (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='推荐表';
```

## 5. 字段字典约定

| 命名 | 约定 |
|---|---|
| `id` | 主键，BIGINT AUTO_INCREMENT |
| `*_time` / `*_at` | 时间戳，DATETIME DEFAULT CURRENT_TIMESTAMP |
| `type` / `status` / `list_type` | TINYINT 枚举，取值范围以注释标注 |
| `cover` / `avatar` | VARCHAR(255)，存 URL 或相对路径 |
| `rating` | DECIMAL(2,1) 0.0~10.0（anime）或 INT 1~10（review） |
| `genre` / `tags` | VARCHAR，逗号分隔标签 |

## 6. 设计要点

- `collection.anime_id` 唯一 → 前端"加入收藏"天然去重，重复 add 被数据库拒绝。
- 删除 `anime` 前必须级联清理其 `collection` / `review` / `recommend`（联表 DELETE）。
- `type-aliases-package: com.semitris.acg.entity` → XML 里可直接用类名（`Anime`、`Collection`…）。
- `collection` / `recommend` / `review` 列表需连表取 `anime.title`、`anime.cover` —— 实体里加非持久化字段（如 `title`、`cover`）即可，无需额外 DTO。
